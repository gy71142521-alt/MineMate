# 矿脉采集作业流程

1. SkillManager 校验参数，获取共享执行槽、Node 实例/代次/租约。读取原点、维度、库存，解析目标物品；已有库存达标则直接验证，不挖掘。
2. inspect_mining_sources 获取真实掉落来源；find_block 的可见候选或玩家明确坐标经 inspect_vein 确认暴露首块矿石。不穿透扫描整片隐藏矿脉。
3. 把首块放入前沿队列。每次成功挖掘后仅检查该坐标的六面邻接、新暴露且同掉落来源的矿石。坐标去重，受 seed 半径和最大矿石数量约束，不跳往另一矿脉。
4. inspect_mining_route 有界加权搜索。保持可靠地面，预留脚部/头部空间；优先无挖掘路径。未知区块、液体、坠落物、设施和不允许的地形阻断路径。不是直接挖 Bot 到目标的整个包围盒。
5. 下一步为 dig 时，mine_route_block 重新规划并只挖当前下一块障碍；为 move 时复用 goto_position(arrival_range=0) 并通过原 taskId 等待。每一步后重新读取真实世界。通道清障不影响普通导航的 canDig=false。
6. ready 后 mine_vein_block 再检查目标、工具、距离、多个可见表面和风险，内部复用基础 digBlock 及 Mineflayer 官方 dig(block,true,'raycast')。只有读取空气确认移除才继续；uncertain/响应未确认不重挖。
7. 先读取背包增量；未入包则 nearby_entities 找到真实 itemName、id、位置。使用同一通道预算接近掉落物，位置每步刷新，最后 collect_item 并独立读取库存。原ID消失/合并时只能在最后位置附近有界重查；库存未增加不得继续挖下一块。
8. 成功拾取后发现新的相邻矿石，继续直到库存达标。矿脉耗尽返回实际缺口；安全路线不存在、预算耗尽、无工具、停止/超时/断线保留真实进度/账本，不伪报完成。
9. 最终独立检查背包汇总数量、初始/最终维度和已挖矿石连通证据。等待租约清理完成后才允许 Runtime 下一项操作。
